# 第一次研究定题

请读取已提供的 Research Memory。我们开始定义第一个具体课题。

先从我提供的信息识别研究目标、对象、已有方法、数据、代码状态、评价方式和资源约束；未知项注明 Unknown。只询问当前阶段真正阻塞的问题，不把所有未知一次变成长问卷。

输出：

1. 一个足够具体的 Research Question，以及本阶段不回答的问题。
2. 至多 3 个候选可证伪 Hypothesis，分别列出支持与反驳它们所需的观察。
3. 最小可行实验：操纵、对照、baseline、测量、有效性、支持 / 反驳 / 结论不足的判据。
4. 所需文献与数据证据；成本和可能的替代解释。
5. 先讨论哪个关键选择以及为什么。

这些先作为讨论提案。只有在对话中明确采用的选择才转为 Decision；讨论结束再输出增量 Update 和必要任务。
